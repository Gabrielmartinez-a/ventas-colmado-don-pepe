# Ventas Colmado Don Pepe

Programa en C++ que pide las ventas de 7 días y calcula el total semanal, promedio diario, día de mayor venta, día de menor venta y días sobre el promedio.

## Autor
- **Nombre:** Gabriel Burgos Martínez
- **Matrícula:** 2026-1768

## Cómo usarlo
1. Compilar con: `C++ main.cpp -o ventas`
2. Ejecutar con: `./ventas`
3. Escribir las ventas de cada día cuando lo pida.

## Qué hace el programa
- Pide las ventas de Lunes a Domingo
- Suma el total semanal
- Calcula el promedio diario
- Muestra cuál fue el día con mayor venta y el de menor venta
- Muestra cuáles días estuvieron sobre el promedio
